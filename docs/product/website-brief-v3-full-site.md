**0.3 Inner-page template**

Every lifecycle and solution page uses the same building blocks, in this order. That consistency is what makes the reference site feel complete.

| **\#** | **Block** | **What it contains** |
|----|----|----|
| 1 | Page hero | Eyebrow (page group), headline, 2–3 sentence intro, breadcrumb (Home › How we work › Plan). Real photo on the right or a light background. |
| 2 | Overview | The areas we cover on this page, as numbered tiles (01, 02…) that jump to the detail below. |
| 3 | Detail | Each area expanded: a heading and 4–9 items, each item with a bold name and a one-line description. |
| 4 | Process | How the work runs, as 4–6 numbered steps in a horizontal line. |
| 5 | What you receive | Numbered list of concrete deliverables or outcomes. |
| 6 | In numbers | Four figures with a label and a short line each. Use counts we control (e.g. "7 workstreams") or confirmed figures only. |
| 7 | Lifecycle strip | Plan → Build → Run → Grow, with the current stage highlighted and marked "You are here". Each stage links to its page. |
| 8 | Where next | Navy band with 4 link cards to related pages (see 0.4). Every page has one. |
| 9 | Closing call to action | Headline and one line specific to the page, plus the button "Book a consultation". |
| 10 | Footer | Same on every page. |

**Part A: Homepage content**

**A0. Voice and tone**

Write the way a senior operator speaks to a CFO: short sentences, concrete nouns, numbers where we have them. If a sentence could appear on any competitor's site, rewrite it.

| **Don't write** | **Write instead** |
|----|----|
| Without the guesswork / with certainty / perfect city | Say what the client gets: "a cost model and a setup plan in two weeks" |
| Seamless, end-to-end, one-stop shop, turnkey | "One contract covers the office, the people, the entity and the books" |
| Unlock, leverage, empower, elevate, accelerate | Plain verbs: set up, hire, run, build, file, hand over |
| World-class, cutting-edge, premier, enterprise-grade, GCC-grade | The actual standard: "ISO 27001-aligned", "fitted out to your global brand guidelines" |
| Integrated platform, ecosystem, synergy, holistic | Name the firms and what each one does |
| Journey, transformation, value creator, powerhouse | State the outcome: "your centre, running, and on your books" |
| AI at the core, AI-first, next-gen | Leave out unless we describe a specific tool |
